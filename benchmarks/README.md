# Benchmarks

Benchmarks live here as definitions and runners. Measurements belong under
`benchmark-results/` and are not committed unless reduced to a small reviewed
evidence snapshot.

Every performance comparison must record executable hashes, runtime versions,
backend, thread count, host information, input hashes, warm-up policy, repeated
runs, elapsed-time statistic, and the precise memory scope being measured.
Scientific accuracy and resource efficiency are separate gates.
